# AI-Driven Employee Training Recommendation System

## Overview

This project presents a machine learning-based recommendation system designed to improve employee productivity by recommending the most effective training methods for each employee.

The project combines Python for data preprocessing and KNIME Analytics Platform for machine learning and decision support.

## Objectives

* Analyze employee performance data
* Segment employees using K-Means Clustering
* Recommend optimal training methods
* Improve organizational productivity

## Technologies

* Python
* KNIME Analytics Platform
* K-Means Clustering
* Decision Trees
* Data Analytics
* Business Intelligence

## Dataset

The dataset contains anonymized information from approximately 500 employees.

## Results

* Maximum productivity improvement: 6.82%
* Average productivity improvement: 4.49%

## Key Skills

* Data Analytics
* Machine Learning
* Recommendation Systems
* Business Intelligence
* Digital Transformation

## Privacy Notice
