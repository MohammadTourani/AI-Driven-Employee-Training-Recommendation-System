# AI-Driven Employee Training Recommendation System

## Overview

This project presents a machine learning-based recommendation system designed to improve organizational productivity through personalized employee training recommendations.

The solution combines Python for data preprocessing and KNIME Analytics Platform for machine learning, employee segmentation, and decision support. The objective is to identify the most effective training method for each employee and support data-driven human resource development.

---

## Project Objectives

* Analyze employee performance and training-related data
* Identify patterns affecting productivity
* Segment employees using K-Means Clustering
* Generate personalized training recommendations
* Support organizational decision-making through data analytics
* Improve workforce productivity and learning effectiveness

## Workflow

The project workflow includes:

1. Data preprocessing and cleaning
2. Missing value handling
3. Feature transformation and encoding
4. Data normalization
5. Employee segmentation using K-Means Clustering
6. Recommendation generation using Decision Trees
7. Rule-based recommendation processing
8. Performance evaluation and visualization

The KNIME workflow can be found in the project screenshots and workflow files.

---

## Dataset

The dataset contains anonymized information from approximately 500 employees, including variables related to:

* Employee characteristics
* Training participation
* Productivity indicators
* Performance-related attributes

To protect privacy and confidentiality, all personally identifiable information and sensitive organizational data have been removed or anonymized.

---

## Methodology

### Data Preparation

Python was used to prepare and preprocess the dataset before importing it into KNIME.

### Employee Segmentation

K-Means Clustering was applied to group employees with similar characteristics and productivity patterns.

### Recommendation Engine

Decision Tree models were used to identify the most suitable training method for each employee group.

### Decision Support

A rule-based recommendation system was developed to generate actionable training recommendations and support managerial decision-making.

---

## Results

The developed recommendation system successfully identified effective training strategies for different employee groups.

### Key Outcomes

* Dataset size: approximately 500 employees
* Maximum productivity improvement: 6.82%
* Average productivity improvement: 4.49%
* Personalized recommendations generated for each employee segment
